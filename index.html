How PICO-8 art works

PICO-8 stores all sprites in one 128×128 sheet of 256 tiles (8×8 each). In a .p8 file that sheet is the __gfx__ section — 128 lines of hex digits, one per pixel.

  1. Make a new .p8 in PICO-8 (or open one).
  2. Use Copy __gfx__ here, then in PICO-8 press Esc to reach the code/file, or edit the .p8 in a text editor and replace its __gfx__ block.
  3. Or use Download PNG sheet and run import sheet.png in PICO-8.
  4. Draw a sprite in code with spr(n, x, y) — the sprite numbers are listed under Export above.
